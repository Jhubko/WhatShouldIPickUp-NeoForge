## What Should I Pick Up

Have you ever broken a chest and ended up with hundreds of items scattered everywhere, forcing you to throw things out just to pick up the one item you actually need?

**What Should I Pick Up** solves that problem by giving you full control over nearby dropped items through a simple and intuitive interface.

### Features

* View all nearby dropped items in a clean overlay
* Drag and drop items directly into specific inventory slots
* Scroll through large piles of items with ease
* Works in multiplayer (server and client required)
* Lightweight and performance-friendly
* Configurable item detection radius up to 5 blocks
* Option to always show the nearby items bar

### Requirements

* Minecraft 1.21.1
* NeoForge

### Installation

1. Install NeoForge for Minecraft 1.21.1
2. Place the mod `.jar` file into your `mods` folder
3. Make sure the server also has the mod installed

### Notes

* Designed to improve inventory management during high item drops (e.g. storage moves, farms)
